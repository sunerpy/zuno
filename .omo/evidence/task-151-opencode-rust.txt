3. Structural fix

- `bridge::truncated_path` became `pub(super)` so ordinary hooks reuse exactly the
  auth-loader marker and pointer semantics instead of inventing a second detector.
- `plugin::invocation_output` is the single ordinary-hook write-back boundary. It now
  obtains the complete returned `args` array, scans every argument recursively, and
  only after every argument passes does it select the mutable output for
  `jsonrpc::apply_hook_output`.
- Rejection identifies plugin id/spec, hook name, argument index, and the
  argument-relative JSON Pointer.
- Because no `apply_hook_output` call occurs until all arguments pass, multi-argument
  mutations are all-or-nothing. A future mutable hook automatically inherits the guard
  because `JsPlugin::call` has no other write-back route.
- No permissive JSON type was tightened. Open JSON schema/options are valid protocol
  data; transport loss is rejected at the shared transport boundary.
- `shim.mjs` is unchanged in the final diff and `MAX_DEPTH = 8` remains enforced.

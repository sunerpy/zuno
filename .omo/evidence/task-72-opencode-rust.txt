Implemented:
- Persist complete oversized tool output before refusing to return it unless the
  raw tool arguments contain accept_large_output=true.
- Include byte count, line count, a transparent four-UTF-8-bytes-per-token
  estimate, the retrieval path, and the literal opt-in field in refusal text.
- Promote foreground shell commands that exceed their attention timeout into a
  queryable local background task without killing or rerunning the process.
- Keep cancellation and the existing 30-minute hard ceiling terminating the
  process group.
- Default the foreground timeout to 120 seconds and cap caller-selected values
  at 600 seconds.

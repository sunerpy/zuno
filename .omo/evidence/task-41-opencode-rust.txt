=== 4. REPORTED DEFECT: THE ORACLE TRUNCATES ITS OWN STDOUT AT 64 KiB ===

Found while building the differential.  5,007-file tree.  Under oc-testkit's ScriptedEnv
(cleared env, temporary HOME) with stdout on a PIPE, 'debug rg files' writes exactly
65536 bytes and loses the rest, deterministically.  The lost region cuts mid-directory,
so it is a flush race on exit, not a search difference.

  scripted env, stdout = pipe, run 1: 65536
  scripted env, stdout = pipe, run 2: 65536
  scripted env, stdout = FILE:        85108
  host env,     stdout = pipe:        85108
  files actually in the tree:         5007

  Consequence for every differential in this project: oc-testkit's run_process captures
  through a pipe, so ANY comparison whose oracle stdout exceeds 64 KiB silently compares
  truncated data and can pass while being wrong.  This suite bounds every invocation
  (STDOUT_BUDGET = 40000) and FAILS LOUDLY if one ever approaches the limit.

=== 5. THE DIFFERENTIAL DESIGN THAT WORKS AROUND IT ===

The 5,007-file tree is covered by 10 disjoint oracle invocations whose union is every
file; each returns at most 1,000 paths (~17 KB).  The union is then compared against ONE
engine call over the whole tree, so the full-tree comparison is not lost:

  pkg000?/**                                 ->  1000 paths,  16999 bytes
  pkg001?/**                                 ->  1000 paths,  16999 bytes
  pkg002?/**                                 ->  1000 paths,  16999 bytes
  pkg003?/**                                 ->  1000 paths,  16999 bytes
  pkg004?/**                                 ->  1000 paths,  16999 bytes
  **/*.md                                    ->     1 paths,      9 bytes
  {.gitignore,.hidden_file.ts,ignored.ts}    ->     3 paths,     37 bytes
  {.hidden_dir,.hidden_dir/**}               ->     1 paths,     20 bytes
  {node_modules,node_modules/**}             ->     1 paths,     25 bytes
  {build,build/**}                           ->     1 paths,     12 bytes

  Note the brace forms.  '.hidden_dir/**' ALONE RETURNS NOTHING on both sides, because a
  whitelist glob is matched against directories too and '.hidden_dir/**' does not match
  '.hidden_dir' itself, so the hidden directory is pruned before its children are seen.
  Verified against the real binary:
    debug rg files --glob '.hidden_dir/**'          ->  (empty)
    debug rg files --glob '{.hidden_dir,.hidden_dir/**}' -> .hidden_dir/inner.ts

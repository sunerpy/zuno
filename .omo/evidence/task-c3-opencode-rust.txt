Defect F — design decision
==========================
The live test now skips cleanly and visibly when a repository-local pinned SDK is
absent. A test-time SDK download was rejected because this Rust repository has no
Node package manifest, lockfile, or install gate; adding network acquisition would
make the test non-hermetic and its version source unauditable. Repository-local
discovery leaves a defensible future seam: vendoring pinned SDK 0.21.0 re-enables
the live test, and the JS report still asserts sdkVersion == 0.21.0.

Implementation completed on 2026-08-12:
- CompatV1State owns the shared AuthStore and a bind-late ProviderOAuthBackend slot. PUT
  /auth/{providerID} writes the recorded body through AuthStore rather than acknowledging it.
- The authorize route invokes the installed provider/method callback and retains the returned
  live callback. The callback route consumes that callback exactly once, converts its success
  value into an oc_auth::Credential, and persists it through the same AuthStore.
- `serve` binds first, then starts the resident plugins with the listener's real URL and installs
  PluginRuntime as the OAuth backend. Plugin shutdown remains tied to server shutdown.
- The embedded JavaScript shim now configures PluginInput.client with HTTP Basic Authorization
  when OPENCODE_SERVER_PASSWORD is non-empty, using OPENCODE_SERVER_USERNAME or the upstream
  default `opencode`. Empty passwords remain auth-disabled and add no header.
- The derived route inventory is measured=20, served=14, unbacked=6, redirected=0. The six
  remaining 501 routes are the previously recorded non-authentication operations.

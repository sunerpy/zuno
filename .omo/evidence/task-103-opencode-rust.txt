IMPLEMENTATION
--------------
- `Config::resolved_memory` accepts `memory: bool` or component options. The
  subsystem defaults on, with 2,200 global characters, 3,000 project characters,
  and a 10-delivered-turn reflection cadence.
- `MemoryStore`, `SessionMemory`, and `MemoryTool` carry the resolved per-scope
  limits. Their existing constructors retain the original defaults.
- `TurnHost::open` freezes resident global/project memory into the session prompt;
  tool-runtime assembly advertises the configured memory tool.
- `ReflectionConfig.enabled` is checked before the cadence counter, policy check,
  Tokio task creation, or runner invocation. This provides the reflection part of
  the master switch without weakening Todo 101's memory-only dispatcher.
- The repository has no production `ReflectionRunner` implementation or reusable
  CLI reflection composition root. Todo 103's required whole-loop integration is
  therefore proved at the public cross-crate boundary in
  `crates/oc-memory/tests/integration.rs`; this task does not invent a second model
  loop or duplicate the foreground turn loop.

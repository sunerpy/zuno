Implemented
===========
- Axum server defaults to 127.0.0.1:0 and prints the kernel-selected URL.
- --hostname/--port overrides are available through `oc-server serve`.
- Empty/absent OPENCODE_SERVER_PASSWORD disables auth; a non-empty password gates every route.
- OPENCODE_SERVER_USERNAME defaults to `opencode` only when absent.
- Unauthenticated non-loopback startup is rejected before bind after DNS resolution.
- Request directory precedence is query `directory`, header `x-opencode-directory`, startup fallback.
- Turn events can be forwarded into fixed-capacity per-subscriber queues.
- Overflow policy is drop-newest with explicit `Delivery::Lagged { dropped }` accounting.

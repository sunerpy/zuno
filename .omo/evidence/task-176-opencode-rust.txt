`client.provider.list()` is the live missing path. Its generated model contract requires the
meaningful source values `release_date`, `reasoning`, `temperature`, `tool_call`, `cost`,
`limit`, and `modalities`. At start, `v1_model` receives a v2 `ModelInfo` after the source
catalogue has already been reduced: it stringifies epoch milliseconds as `release_date`,
hard-codes reasoning/temperature, and cannot faithfully reproduce long-context cost metadata.
The repair therefore must project the specialized legacy response directly from the canonical
models.dev document rather than reverse-project the lossy `/api/model` wire value.

adding a new arrival kind cannot default silently to an unprojected path.

IMPLEMENTATION
--------------------------------------------------------------------------------
`crates/oc-plugin/src/js/projection.rs` now defines the complete arrival vocabulary through
`GeneratedClientArrival` and `JsModelArrival`. Its exhaustive `projection()` match has no
wildcard arm. It classifies `/config/providers` honestly as `Unbacked`, `/provider` as the
specialized `LegacyCatalogHttp` projection, all three v2 model/provider catalogue operations,
lightweight selections, ordinary hook callbacks, and retained resource callbacks. Production
entry points in `jsonrpc.rs`, `js/bridge.rs`, and `js/host.rs` consume that classification, so a
new arrival class cannot silently inherit an unprojected default.

`crates/oc-server/src/api/provider.rs` now projects a typed legacy provider/model document
directly from canonical models.dev data while reusing `CatalogView` for availability. The
projection preserves provider API/env/npm metadata and model identity, exact release date,
reasoning/temperature/tool-call flags, modalities, limits, status, headers/options, npm override,
and complete costs including zero-valued cache prices and `context_over_200k`. The legacy
`/provider` handler in `compat_v1.rs` delegates to this canonical projection rather than trying
to reverse-project the already-reduced v2 `ModelInfo`; epoch milliseconds can therefore no
longer become a decimal `release_date` string.

`crates/oc-cli/tests/generated_sdk_provider.rs` starts the production `ServerBuilder` plus
`compat_v1_router`, loads the real installed `@opencode-ai/sdk@1.15.13`, and invokes
`PluginInput.client.provider.list()`. It proves JavaScript observes the generated SDK spelling
and meaningful model values rather than a hand-authored HTTP fixture.

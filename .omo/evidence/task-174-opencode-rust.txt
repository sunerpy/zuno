1. Authoritative upstream contract

Source checkout: /config/workspace/ProdDir/AI/opencode

packages/opencode/src/plugin/shared.ts:194-204:
- reads package.json `engines.opencode` only;
- skips the check when the host version is invalid or has major version zero;
- evaluates the declared range with npm `semver.satisfies`;

packages/opencode/src/plugin/loader.ts:123-139:
- applies compatibility only when the resolved source is `npm`;

identity. This task changes the manifest field and rejection behavior, not that

4. TDD regression and implementation

The first production-loader run used:
  CARGO_TARGET_DIR=/tmp/opencode/t174 cargo test -p oc-plugin --test js \
    js_version_gate -- --nocapture

Before implementation, the satisfying-range control passed after its fixture
received a real minimal SDK module. The excluding-range case failed because the
loader returned one active plugin, produced no compatibility diagnostic, and
created the factory activation marker. This isolated the defect from SDK setup.

Implementation changes:
- `PackageManifest` reads `engines` as JSON metadata and gates only when its
  `opencode` member is a string, matching upstream's type check;
- the old `dependencies`/`peerDependencies["@opencode-ai/plugin"]` gate and its
  exported package-name constant are removed;
- npm-compatible exact, partial/wildcard, comparator-set, caret, tilde, hyphen,
  and OR range forms are evaluated without substituting Bun's range behavior;
- invalid ranges such as `latest` are unsatisfied, as npm `semver.satisfies`
  returns false rather than Bun's permissive true;
- `load_one` converts `VersionGate::Unsatisfied` directly into an actionable
  compatibility diagnostic before `JsHostBuilder::start`, so no import,
  factory, hook registration, or callback can occur;
- npm packages with satisfying or absent ranges still load, while file plugins
  retain their upstream development-code bypass.

After implementation, all three named production regressions passed:
- `js_version_gate_skips_an_excluding_engines_opencode_package_before_activation`;
- `js_version_gate_loads_a_satisfying_engines_opencode_package`;
- `js_version_gate_rejects_a_non_semver_engines_opencode_range`.

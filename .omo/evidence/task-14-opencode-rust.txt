### ORACLE MEASUREMENTS that changed the implementation
  1. `opencode debug skill` TRUNCATES ITS OWN STDOUT WHEN STDOUT IS A PIPE.
     $ for i in 1 2 3; do opencode debug skill | wc -c; done   -> 40960 40960 57344
     $ for i in 1 2 3; do opencode debug skill > f; wc -c < f; done -> 2807771 x3
     debug/skill.ts ends with a bare process.stdout.write and the process exits
     without draining. oc_testkit::Oracle::run captures through a pipe, so it
     cannot be used for this command; the differential redirects to a file.

  2. THE ORACLE'S DUPLICATE-NAME WINNER IS RACY.
     Fixture: name `dupe` under ~/.claude, ~/.agents and the config skill dir.
     Three consecutive runs reported the winner as .agents, config, config.
     Cause: skill/index.ts:240-243 loads every match with concurrency:"unbounded".
     Same three runs over the real tree: name set identical, location set differed.
     This port loads in root order (later root wins), which reproduces the oracle's
     real-tree result for every alias on this machine and is reproducible.

  3. skills.paths[] RELATIVE ENTRIES RESOLVE AGAINST THE CWD, NOT THE WORKTREE.
     skill/index.ts:213 is path.join(directory, expanded). Verified in a git repo
     with the process in proj/sub/deeper: relskills under the CWD was found,
     relskills under the repo root was not. The plan's "relative to workspace" is
     wrong; the oracle's behaviour is implemented.

  4. THE CLAUDE SWITCH ALSO SILENCES THE PROJECT WALK.
     externalDirs is built once (skill/index.ts:186-188) and reused for the $HOME
     probe and the ancestor walk. OPENCODE_DISABLE_CLAUDE_CODE_SKILLS=1 removed
     both ~/.claude and proj/.claude skills. OPENCODE_DISABLE_CLAUDE_CODE=1 is
     equivalent. OPENCODE_DISABLE_EXTERNAL_SKILLS=1 removed roots 1-3.
     OPENCODE_DISABLE_PROJECT_CONFIG=1 did NOT remove root 3 (it gates root 4 only).

  5. FRONTMATTER: ONLY name AND description ARE READ -- CONFIRMED, NOT ASSUMED.
     A file with license/allowed-tools/version alongside name+description loaded
     with those keys ignored. Rejections measured: no name; name: 123; name: true;
     description: (null); description: 42; a sequence document; ---- (four dashes,
     not a delimiter); a comment-only block. Accepted: name: yes (YAML 1.2 core
     keeps it a string -- this is why yaml-rust2 was chosen over serde_yaml, whose
     YAML 1.1 would make it a boolean); ---yaml and ---json language tags; a
     missing closing delimiter (frontmatter parses, content becomes empty); CRLF
     (content keeps its \r); an unquoted colon in a value (sanitize retry);
     folded > scalars.

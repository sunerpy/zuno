# Task 46 evidence — remote MCP transports and OAuth

## Scope

Implemented remote MCP support in `crates/oc-mcp`:

- Streamable HTTP first, legacy SSE fallback on non-authentication failures
- JSON and `text/event-stream` Streamable HTTP responses
- legacy SSE `endpoint` discovery plus POST message delivery
- shared JSON-RPC waiter routing extracted from the stdio transport
- initialization, protocol-version negotiation, sessions, pagination, tool calls, headers, and deadlines
- OAuth protected-resource and authorization-server discovery
- configured clients, RFC 7591 dynamic registration, PKCE S256, CSRF state, authorization-code exchange, and refresh-token exchange
- `mcp-auth.json` persistence through `oc-auth`, including mode `0600` and redacted debug output

## Deterministic coverage

Command:

```sh
cargo test -p oc-mcp --test remote --offline
```

Result: 8 passed, 0 failed.

The tests prove plain JSON Streamable HTTP, legacy SSE fallback order, static headers, bounded timeouts, `oauth:false`, DCR, PKCE challenge derivation, callback-port and explicit-redirect precedence, configured client id/secret exchange, refresh before handshake, token persistence, state/verifier cleanup, mode `0600`, and secret-safe debug rendering.

The stdio refactor retained its existing behavior:

```text
cargo test -p oc-mcp --lib stdio --offline
9 passed, 0 failed
```

## Real-server proof

Command:

```sh
cargo test -p oc-mcp --test remote_live --offline -- --nocapture
```

Result: 1 passed, 0 failed; both configured public endpoints were reachable and returned non-empty real tool catalogs.

Observed initialize summaries:

```json
{"server":"aws-knowledge-mcp-server","protocolVersion":"2025-03-26","serverInfo":{"name":"AWSKnowledgeMCP","version":"1.0.0"}}
{"server":"microsoft-learn","protocolVersion":"2024-11-05","serverInfo":{"name":"Microsoft Learn MCP Server","version":"1.0.0"}}
```

AWS completed over Streamable HTTP with a JSON response and advertised five tools. Microsoft completed through the legacy SSE fallback and advertised three tools. The test prints the complete real initialize and `tools/list` JSON under `--nocapture`; unreachable endpoints produce an explicit `SKIP` line instead of substituting a fixture.

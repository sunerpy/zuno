extract.py (self-checking: exits non-zero on any unparsed row or a count != 184):

  import re, sys
  src = open(sys.argv[1], encoding="utf-8").read()
  lines = src.splitlines()
  def block(start_marker, end_marker):
      a = next(i for i, l in enumerate(lines) if l.startswith(start_marker))
      b = next(i for i, l in enumerate(lines[a:], a) if l.startswith(end_marker))
      return lines[a + 1 : b]
  cmd = {}
  for l in block("export const CommandMap = {", "} satisfies BindingCommandMap"):
      m = re.match(r'\s*("?)([A-Za-z0-9_.]+)\1:\s*"([^"]*)",\s*$', l)
      if m: cmd[m.group(2)] = m.group(3)
  entry = re.compile(r'^\s*("?)(?P<name>[A-Za-z0-9_.]+)\1:\s*keybind\((?P<val>.*?),\s*"(?P<desc>(?:[^"\\]|\\.)*)"\)\s*,?\s*$')
  rows = []
  for l in block("export const Definitions = {", "} satisfies Record<string, Definition>"):
      if "keybind(" not in l: continue
      m = entry.match(l)
      if not m: sys.exit(f"unparsed keybind entry: {l!r}")
      val, name, desc = m.group("val").strip(), m.group("name"), m.group("desc")
      prevent = ""
      if val.startswith("{"):
          k = re.search(r'key:\s*"([^"]*)"', val); p = re.search(r'preventDefault:\s*(true|false)', val)
          if not k: sys.exit(f"object default without a string key: {val!r}")
          keys, prevent = k.group(1), (p.group(1) if p else "")
      elif val == "LeaderDefault":
          keys = re.search(r'export const LeaderDefault = "([^"]*)"', src).group(1)
      elif val.startswith('"'): keys = val[1:-1]
      else: sys.exit(f"unhandled default expression: {val!r}")
      rows.append((name, keys, cmd.get(name, name), prevent, desc))
  if len(rows) != 184: sys.exit(f"expected 184 entries, extracted {len(rows)}")
  print("# name\tkeys\tcommand\tprevent_default\tdescription")
  for r in rows: print("\t".join(r))

3. MEASURED FACTS THAT DECIDED THE DESIGN
=====================================================================
Multi-key + leader-mixing (keybind.ts:48): app_exit = "ctrl+c,ctrl+d,<leader>q".
  28 of 184 defaults contain "<leader>"; 28 carry more than one comma-separated
  spelling. So the table is action -> [sequence...], never action -> key.

Scope derivation, measured over the real table:
  rule "first `_` segment"            -> 33 scopes,  1 conflicting (scope,key) pair
                                         ('dialog','return'): dialog.select.submit
                                         vs dialog.prompt.submit
  rule "namespace before last `.`,
        else first `_` segment"       -> 39 scopes,  0 conflicting pairs
The second rule is what is implemented. The shipped defaults are therefore
conflict-free by construction, so any conflict a build reports comes from user
config -- which is what makes conflict reporting useful instead of noise.
39 namespaces = 38 action scopes + `leader`.

Modifier/base-key inventory over all defaults:
  modifiers: LEADER, alt, ctrl, shift, super
  base keys: - . 1..9 ? E [ ] a b backspace c d delete down e end escape enter f
             f2 g h home i j k l left m n p pagedown pageup q r return right s
             space t tab u up v w x y z
`enter` and `return` both appear and are one physical key; `E` (bare uppercase)
and `shift+i` are the same shape spelled two ways; `?` is a shifted glyph a
terminal may report with or without the SHIFT flag. Chord::new normalizes all
three so a config written either way resolves.

43 of 184 defaults are "none" (unbound).

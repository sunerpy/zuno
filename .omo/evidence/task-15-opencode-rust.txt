3. MCP PROMPT NAMING — A DETAIL WITH TEETH
--------------------------------------------------------------------------------

MCP entries are NOT keyed by the prompt's own name.
`packages/opencode/src/mcp/catalog.ts:100-105` keys them

    sanitize(client) + ":" + sanitize(prompt)
    sanitize = value.replace(/[^a-zA-Z0-9_-]/g, "_")     (catalog.ts:113)

So prompt `hello` on server `srv` is the command `srv:hello`, confirmed at slot
[7] above. Level 3 IS an unconditional overwrite, but in practice it can only
fire against a config command whose key is literally the colon-qualified name —
which is why the probe had to declare `command["srv:hello"]` to observe (b).

ARGUMENT MAPPING (`command/index.ts:117-118`): the server is asked for its
prompt with every declared argument bound to the LITERAL string "$1", "$2", ...
so the returned text still carries those placeholders and normal expansion then
fills them with the user's real arguments. Captured from the probe server's
stderr:

  REQ prompts/get {"name": "hello", "arguments": {"alpha": "$1", "beta": "$2"}}

Messages are joined with "\n"; a non-text content block becomes "" but is still
joined; an absent/empty result becomes "" (`command/index.ts:121-126`).

4. ARGUMENT EXPANSION — 59-CASE DIFFERENTIAL
--------------------------------------------------------------------------------

Oracle: `packages/opencode/src/session/prompt.ts:1372-1395`, regexes at
`:1594-1596`; hints at `command/index.ts:36-43`.

  argsRegex        /(?:\[Image\s+\d+\]|"[^"]*"|'[^']*'|[^\s"']+)/gi
  placeholderRegex /\$(\d+)/g
  quoteTrimRegex   /^["']|["']$/g

Method: `crates/oc-catalog/tests/fixtures/command_expansion_oracle.cjs` is a
VERBATIM transcription of the oracle's expansion body and its three regexes
(only the Effect wrappers and the later !`bash` step removed). Run under node
v26.5.0 over 59 cases to produce the golden file. The Rust implementation is
diffed against that golden, and the golden is re-derived at test time whenever
node is present, so it cannot rot into a self-consistent fiction.

  $ node tests/fixtures/command_expansion_oracle.cjs \
         tests/fixtures/command_expansion_cases.json \
       > tests/fixtures/command_expansion_expected.json
  cases: 59, unique ids ok

OBSERVED BEHAVIOUR, EVERY EDGE CASE THE PROMPT ASKED ABOUT AND SEVERAL IT
DID NOT:

  #  input                                                  oracle output
  -- ------------------------------------------------------ --------------------
  $3 WITH ONLY TWO ARGS  (the prompt's failure scenario)
     tmpl 'A=[$1] B=[$2] C=[$3]'   args 'one two'
     -> 'A=[one] B=[two] C=[]'     EMPTY, confirmed, no panic

  $ARGUMENTS WITH ZERO ARGS
     tmpl 'Input: $ARGUMENTS'      args ''     -> 'Input:'
     tmpl 'Input: $ARGUMENTS'      args '   '  -> 'Input:'   (final trim)

  A BARE $ NOT FOLLOWED BY A DIGIT
     tmpl 'COST IS $5.00 and $x and $'  args 'one two'
     -> 'COST IS .00 and $x and $'
     $5 IS a placeholder (missing -> empty), so a price loses its digits.
     $x and a trailing $ are literal.  hints = ['$5']

  $10 — IS IT $1 THEN 0, OR THE TENTH ARGUMENT?
     THE TENTH. \d+ is greedy.
     tmpl 'T=[$10] ONE=[$1]'  args 'a b c d e f g h i j k'
     -> 'T=[j k] ONE=[a]'     ($10 is the highest, so it is greedy)
     hints = ['$1','$10']

  *** THE HIGHEST PLACEHOLDER IS GREEDY *** (not stated in the prompt)
     tmpl 'A=[$1] B=[$2]'   args 'one two three four'
     -> 'A=[one] B=[two three four]'
     tmpl 'only: $1'        args 'one two three'  -> 'only: one two three'
     tmpl 'B=[$2] A=[$1]'   args 'one two three'  -> 'B=[two three] A=[one]'
     tmpl 'A=[$1] C=[$3]'   args 'one two three four' -> 'A=[one] C=[three four]'

  *** $0 IS A JAVASCRIPT ARTEFACT ***
     tmpl 'Z=[$0] ONE=[$1]' args 'one two' -> 'Z=[undefined] ONE=[one two]'
        args[-1] is undefined, stringified by the replacer.
     tmpl 'only: $0'        args 'a b c'   -> 'only: c'
        when $0 is itself the highest, slice(-1) makes it the LAST argument.
     tmpl 'only: $0'        args ''        -> 'only:'
     tmpl 'Z=[$00] ONE=[$1]' args 'one two' -> 'Z=[undefined] ONE=[one two]'
     tmpl 'A=[$01] B=[$2]'  args 'one two three' -> 'A=[one] B=[two three]'

  APPEND FALLBACK (no placeholder at all, non-blank input)
     tmpl 'NO PLACEHOLDERS HERE'  args 'trailing input'
     -> 'NO PLACEHOLDERS HERE\n\ntrailing input'
     args ''      -> 'NO PLACEHOLDERS HERE'
     args '  \t ' -> 'NO PLACEHOLDERS HERE'   (blank is not appended)
     Any $N or $ARGUMENTS suppresses the append.

  $ARGUMENTS IS THE RAW INPUT; $N ARE TOKENIZED
     tmpl 'P=[$1] ALL=[$ARGUMENTS]'  args '"quoted arg"  spaced'
     -> 'P=[quoted arg spaced] ALL=["quoted arg"  spaced]'
     Quotes and the double space survive only in $ARGUMENTS.

  *** $ PATTERNS INSIDE THE USER'S INPUT ARE INTERPRETED — FOR $ARGUMENTS ONLY
     Because :1391 calls replaceAll with a STRING replacement, ECMA-262
     GetSubstitution runs over the user's own arguments:
       args 'cost $$ high' -> 'ALL=[cost $ high]'          $$ collapses
       args '$& weird'     -> 'ALL=[$ARGUMENTS weird]'     $& = matched text
       args 'x $` y' with tmpl 'pre ALL=[$ARGUMENTS] post'
                           -> 'pre ALL=[x pre ALL=[ y] post'   $` = prefix
       args "x $' y" same tmpl
                           -> "pre ALL=[x ] post y] post"      $' = suffix
     Positional substitution uses a FUNCTION replacer, so it does NOT:
       tmpl 'P=[$1]'      args '$$ tail' -> 'P=[$$ tail]'
       tmpl 'P=[$1] Q=[$2]' args '$& tail' -> 'P=[$&] Q=[tail]'

  NON-ASCII DIGITS ARE NOT PLACEHOLDERS  (JS \d is ASCII-only)
     tmpl '$٣ and $1'  args 'a b'  -> '$٣ and a b'   hints = ['$1']

  ABSURD NUMBERS DO NOT PANIC
     tmpl '$999' -> ''      tmpl '$99999999999999999999' -> ''

  TOKENIZER
     'one    two\tthree'    -> ['one','two','three']    (runs collapse)
     '"hello world" second' -> ['hello world','second'] (quotes group + strip)
     "'hello world' second" -> ['hello world','second']
     '[Image 3] caption'    -> ['[Image 3]','caption']  (one token)
     '[image 12] tail'      -> ['[image 12]','tail']    (the /i flag is real)
     '" second'             -> ['second']    UNPAIRED QUOTE SKIPPED ENTIRELY
     '"unclosed second'     -> ['unclosed','second']
     '"" second'            -> ['','second'] EMPTY QUOTED RUN = EMPTY TOKEN
     "don't stop"           -> ['don','t','stop']  apostrophe opens a group
     '日本語 テスト 三つ'    -> ['日本語','テスト','三つ']

  HINTS ARE DEDUPED THEN SORTED *LEXICOGRAPHICALLY*, NOT NUMERICALLY
     '$2 and $10'      -> ['$10','$2']      <- observed, string sort
     'T=[$10] ONE=[$1]'-> ['$1','$10']
     '$1 and $1 and $2'-> ['$1','$2']
     '$01 and $1'      -> ['$01','$1']      raw spelling preserved
     $ARGUMENTS is appended AFTER the sort, never inside it.

  ALWAYS TRIMMED
     '   $ARGUMENTS   ' + 'mid' -> 'mid'
     '   $1   '         + ''    -> ''

release (`/tmp/t163-upstream-exact.gAiEpx`). Upstream reported the two global URLs
but not bare `./plugin` or `./plugins`. Thus “project trees” in the old guide was
ambiguous; upstream's actual project locations are `.opencode/plugin` and
`.opencode/plugins`.

Decision: option (a), wire it. Upstream implements discovery, the existing Rust
function is complete, and only the production connection was absent. The docs are
tightened to name configuration directories and project `.opencode` explicitly;
no divergence is declared because the result matches upstream.

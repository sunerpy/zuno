Task 161 — merge runtime-discovered config into debug config
Closes F1 blocker 2, F2-B1, F4 blocker 1, and criterion 2's disclosed gap.

DEFECT AND FIX
--------------------------------------------------------------------------------
The config loader already found Markdown agents for `agent list`, but `debug config`
serialized only the typed Config structure. It therefore omitted runtime Markdown
agents, Markdown commands, and plugin provenance.

The fix:
- shares the recursive Markdown walker and naming rules between agents and commands;
- adds a command loader with config-directory and OPENCODE_CONFIG_CONTENT precedence;
- merges runtime agent and command maps into `debug config`;
- reconstructs source-ordered `plugin_origins` as `{spec, source, scope}` and
  deduplicates package identities with the same last-wins rule as plugin loading;
- normalizes exactly representable integral f64 values to JavaScript JSON integers;
- uses the command loader in TurnHost while overlaying plugin-mutated config last.

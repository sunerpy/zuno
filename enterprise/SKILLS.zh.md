# 企业 Skill 评测与激活

Skill 评测是在现有学习 Job、Worker 租约和模型计量底座上执行的明确审核任务。
它不会因为会话结束就自动启动，也不借用私人 Memory 自动维护授权。

## 模型配置

不可变 Agent 定义可通过 `skillEvaluation` 引用同工作区内已安装的
completion-only 配置。该配置决定实际模型、凭证与预算，Agent 步数为 1–8，
模型凭证保留在 Worker。定义中没有该引用时，不提供对应 Skill 评测能力，
不会静默选择默认模型。

基线与候选使用同一模型／尝试设置及固定案例。工具仅返回录制结果，不提供环境、
文件、MCP 或命令执行器。每次尝试产生答案与轨迹，再由独立模型请求根据预期
行为评分。本地和分布式评测共用失败／保护案例比较规则。

## 候选与审核 API

| 路由 | 行为 |
| --- | --- |
| `POST /api/v1/jobs/{sourceJob}/skills` | 将私人候选绑定到本人已完成 Job 及其已安装配置 |
| `GET /api/v1/skills/{candidate}` | 读取精确基线、候选、案例、模型引用、状态与报告 |
| `POST /api/v1/skills/{candidate}/evaluate` | 按候选摘要批准评测，并原子派发 Job |

候选包含名称、基线／建议内容与 1–8 个固定案例。每例包含稳定 ID、情景、预期
行为、录制工具调用、类型（失败／保护／一般）和权重。这些是明确提交的评测
情景，不会自动成为真实业务成功的证据。每例最多 16 个录制调用，候选 JSON
最多 128 KiB。

审核要求有效的人类主体使用获准审核应用。仅提交候选不会发起模型请求。
审核、Job 接纳、请求回执和审计原子提交，重复请求 ID 复用原 Job。失败或取消
后可明确重新审核，创建新 Job，并保留此前运行和计量。

SDK 提供 `proposeSkill`、`skillCandidate`、`evaluateSkill`。已有学习 Job
详情及取消 API 同时支持 `skill_evaluation`，公共活动类型为 `SkillEvaluation`。
响应不包含 Worker 凭证或私有租约 token。本轮不交付 App/UI。

## 运行与证据

学习协议 2 添加 Skill 输入／结果类型。PostgreSQL 预览格式 26 保存私人候选、
审核、审计和请求，复用学习执行租约、截止时间、预算与模型日志。精确格式 25
升级保留会话、消息、个人／共享 Memory 和 MCP 记录。

每次模型请求绑定已批准案例、基线／候选角色、已安装模型和录制工具 Schema，
请求数、输入体积、输出与总计量均有边界。更换 Worker 不重置 Job 的已计量或
预留 token，不明确的模型结果保守计量，合法迟到用量可核销既有预留。

评分请求准入前，数据端从持久模型结果和固定 cassette 重建尝试轨迹，答案、
轨迹和未匹配调用数必须与评分输入一致。最终分数必须对应已记录评分输出；
通过状态和汇总指标由数据端重新计算，不能只提交 `passed: true` 就完成评测。

只有持久尝试支持时，步数耗尽才能结算为失败观察。取消、撤权和过期租约阻止
新的模型请求。目前 Worker 丢失后重启案例序列，不迁移在途 provider stream，
仍受同一持久 Job 预算约束。

## 带版本的安装

评测通过不会自动安装或激活。所有者通过获准审核应用分别执行安装、激活及
回退，每次操作重新检查当前组织授权，绑定请求 ID 和预期版本。安装记录保留
精确候选摘要、正文以及已完成的评测证据。

| 路由 | 行为 |
| --- | --- |
| `POST /api/v1/skills/{candidate}/install` | 保存已评测正文；首次安装预期版本为 `0` |
| `GET /api/v1/workspaces/{workspace}/skills` | 分页读取本人安装元数据 |
| `GET /api/v1/installed-skills/{skill}` | 读取本人正文与当前版本 |
| `POST /api/v1/installed-skills/{skill}/activation` | 明确激活或停用当前版本 |
| `POST /api/v1/installed-skills/{skill}/rollback` | 将历史正文和证据恢复为新的未激活版本 |

安装按所有者、工作区和经过校验的名称唯一标识。替换要求评测基线与当前正文
一致，并通过版本 CAS。每次安装和回退都先停用，需单独激活。正文、版本历史
及请求回执原子提交。每工作区最多安装 64 项，正文最多 32 KiB，描述最多
1,200 UTF-8 字节。

该后端使用原生**嵌入式 Skill**：正文保存于 PostgreSQL，复用 `Skills` 目录
及 `skill` 工具。每次模型请求前刷新有界元数据索引，`list`、`search`、`load`
复用原生身份及分页规则。加载前后检查当前所有权、租约及激活状态；来源标识
包含安装版本，因此旧版本或已停用来源不能继续加载。已记录正文仍保留在持久
历史中，停用影响后续发现和读取。

内部状态服务不扫描控制面宿主目录。嵌入式 Skill 没有资源根目录，
`read_resource` 明确报告此限制；资源包／工作区安装和基于证据的自动提案仍待
后续实现。completion 配置不暴露 Skill 工具。

PostgreSQL 预览格式 27 增加安装、版本与请求表，强制执行所有者 RLS。
精确格式 26 迁移测试保留已评测候选、会话、消息及 Memory，并覆盖注入故障
后的整体回滚。SDK 提供 `installSkill`、`installedSkills`、`installedSkill`、
`activateSkill`、`rollbackSkill`。不包含 App/UI。

# 子任务工作区准备

已配置企业子任务会从父工作区的命名不可变快照创建独立 Docker 工作区。Agent Worker
可以在不同 Linux 机器上运行；首个 Docker fork 适配器要求父子环境属于同一配置网关，
尚未公布跨网关快照传输能力。

## 配置目标

在控制面及兼容 Worker 安装子定义。以下命令只验证并输出规范化引用，不启动服务或读取
凭据：

```sh
zuno-enterprise --definition-ref /etc/zuno-enterprise-preview/helper.json
```

把输出加入父定义的可选 `delegation.targets`：

```json
{
  "delegation": {
    "targets": [
      {"id": "helper", "version": 1, "sha256": "<--definition-ref 输出的摘要>"}
    ],
    "maximumDepth": 2,
    "maximumChildren": 4
  }
}
```

这是配置模板。目标必须匹配精确 ID、版本、摘要、工作区和网关；子定义内容改变后必须
更新父引用及版本。每个 Agent 名只对应一个已安装子定义。子任务使用该定义固定的原生
provider／model 和凭据引用，普通 task 调用不能注入任意模型／effort 选项覆盖。

只有存在有效目标，Worker 才安装原生 `task`。契约、目标和深度检查仍由原生 TaskTool
执行。有效深度上限持久保存到子会话，后续委派和续接只能收窄，子定义不能自行扩大父授权。

## 接纳与恢复

首次子请求只记录意图并返回稳定 Job／会话 ID。需要工作区的子任务在准备得到持久确认前
不可领取；后台模式也先完成准备，再返回可执行 Job 句柄。

Worker 协议 9 通过网关协议 3 请求 `PrepareChildWorkspace`，请求只携带已暂存子 Job ID。
控制面核验父租约、子归属，解析父子环境规格并记录准入；Worker 不能自行选择其他卷、
镜像、网关或宿主路径。

网关按稳定子 Job ID 命名父快照，再恢复到目标工作区。账本格式 3 在 Docker 写入前保存
fork 意图，并用随机所有权 nonce 标记目标卷；环境公布和 fork 回执原子提交。已完成
fork 的重试返回已有环境，不覆盖子任务后续修改。

未公布的中断复制只允许清理并重建其自身 nonce 匹配的卷和从未启动的传输容器。名称
相同或只有普通环境标签都不足以授权删除；`acquire` 也不能将半复制目标变成可执行空环境。

网关通过服务身份发布准备回执。真实迟到回执可以在原租约失效后保存，但不恢复旧 Worker
的执行权。相同重试取回原回执，不再次复制；父检查点接纳或后台最终接纳仍检查当前授权。

`task_id` 续接保留已有子工作区。已准备子环境的获取使用 `get`，不在丢失后静默回退到
空卷。丢失环境必须显式恢复。工作区继承不等于命令批准，子命令继续经过当前用户审批和
租约检查；子修改留在独立卷，进入父工作区仍需独立的可审批合并流程。

## 迁移与验证

PostgreSQL 格式 11 增加作用域化准备／回执和继承深度上限，保留格式 1–10。旧子会话
不会推断出更宽的委派授权。精确旧格式测试保留会话、Memory 和暂存子任务，在故障时
回滚到旧标记。网关格式 3 原子升级格式 1–2，保留环境、命令回执和快照。

真实 Docker 测试覆盖子任务修改后与重启后的 fork 重试、公布失败、半复制环境拒绝
获取、拒绝接管其他账本卷。已认证网关测试丢弃准备确认后取回相同回执，并验证继承文件、
子写入不修改父工作区。

独立可执行测试运行一个控制面、一个网关和两个 Worker，覆盖两个用户、真实父／子
Job、十四次模型请求、四次人工命令审批、私有 Memory 及 SIGTERM 退出。模型采用确定性
fixture；任务树取消见[控制](CONTROL.zh.md)。可审批合并、跨网关传输、
Workflow／Council 和剩余 P5–P6 验收继续推进。

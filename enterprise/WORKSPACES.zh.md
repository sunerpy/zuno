# 子任务工作区准备

已配置企业子任务会从父工作区的命名不可变快照创建独立 Docker 工作区。Agent Worker
可以在不同 Linux 机器上运行；首个 Docker fork 适配器要求父子环境属于同一配置网关，
尚未公布跨网关快照传输能力。

## 初始化项目

经过认证、使用配置中审批应用的用户，可以在根会话接纳首轮输入前初始化项目。
先创建会话，再向 `POST /sessions/{session}/workspace/imports` 提交
`requestId`、`expectedInputVersion: "0"`、归档 `sha256` 和十进制字符串 `bytes`。
通过 `PUT /sessions/{session}/workspace/imports/{import}/archive` 上传相同的未压缩
tar 字节，类型为 `application/x-tar`；API 和 BFF 前缀共用契约。
`GET /sessions/{session}/workspace/imports/{import}` 返回类型化状态。

归档条目必须位于 `workspace/` 下，总量不超过 512 MiB，只接受受支持的 UTF-8 文件、
目录、符号链接和硬链接。拒绝特殊文件、set-id 模式、越界链接、重复条目和结构冲突。
初始化将 UID／GID 规范化为运行用户 `0:0`，保留内容、普通权限及安全链接；数据流式写入
私有暂存文件，不解包到网关宿主。

导入接纳与首轮输入通过同一会话锁串行化，上传／恢复期间不接纳 Job。控制面固定所有者、
配置和环境；独立短期上传票据不能执行命令，也不能读取其他资源。字节校验后，网关再次
检查当前初始化权限，复用持久分叉机制发布环境并提交匹配回执。就绪工作区始终按已有
环境打开，卷丢失不能静默变成空目录。

相同请求和上传（包括并发重试）返回同一结果，不同字节或参数冲突。初始化开始前可对
import 资源发送 `DELETE` 取消；恢复已开始时，重试相同归档或查看状态。不能通过初始化
覆盖就绪数据；取消后的上传可在任何输入接纳前重新创建。当前适配器固定所选配置，
配置／环境变化需显式迁移。之后 Agent 执行命令仍需独立审批。

SDK 提供 `beginWorkspaceImport`、`workspaceImport`、`uploadWorkspaceArchive`、
`cancelWorkspaceImport`。就绪导入以 artifact 和 `ViewWorkspaceImport` 投影，不暴露
私有配置或凭证。PostgreSQL 格式 18 在控制面重启后保留状态。

## 配置目标

在控制面及兼容 Worker 安装子定义。以下命令只验证并输出规范化引用，不启动服务或读取
凭据：

```sh
zuno-enterprise --definition-ref /etc/zuno-enterprise-preview/helper.json
```

把输出加入父定义的可选 `delegation.targets`：

```json
{
  "delegation": {
    "targets": [
      {"id": "helper", "version": 1, "sha256": "<--definition-ref 输出的摘要>"}
    ],
    "maximumDepth": 2,
    "maximumChildren": 4
  }
}
```

这是配置模板。目标必须匹配精确 ID、版本、摘要、工作区和网关；子定义内容改变后必须
更新父引用及版本。每个 Agent 名只对应一个已安装子定义。子任务使用该定义固定的原生
provider／model 和凭据引用，普通 task 调用不能注入任意模型／effort 选项覆盖。

只有存在有效目标，Worker 才安装原生 `task`。契约、目标和深度检查仍由原生 TaskTool
执行。有效深度上限持久保存到子会话，后续委派和续接只能收窄，子定义不能自行扩大父授权。

## 接纳与恢复

首次子请求只记录意图并返回稳定 Job／会话 ID。需要工作区的子任务在准备得到持久确认前
不可领取；后台模式也先完成准备，再返回可执行 Job 句柄。

Worker 协议 11 通过网关协议 4 请求 `PrepareChildWorkspace`，请求只携带已暂存子 Job ID。
控制面核验父租约、子归属，解析父子环境规格并记录准入；Worker 不能自行选择其他卷、
镜像、网关或宿主路径。

网关按稳定子 Job ID 命名父快照，再恢复到目标工作区。账本格式 3 在 Docker 写入前保存
fork 意图，并用随机所有权 nonce 标记目标卷；环境公布和 fork 回执原子提交。已完成
fork 的重试返回已有环境，不覆盖子任务后续修改。

未公布的中断复制只允许清理并重建其自身 nonce 匹配的卷和从未启动的传输容器。名称
相同或只有普通环境标签都不足以授权删除；`acquire` 也不能将半复制目标变成可执行空环境。

网关通过服务身份发布准备回执。真实迟到回执可以在原租约失效后保存，但不恢复旧 Worker
的执行权。相同重试取回原回执，不再次复制；父检查点接纳或后台最终接纳仍检查当前授权。

`task_id` 续接保留已有子工作区。已准备子环境的获取使用 `get`，不在丢失后静默回退到
空卷。丢失环境必须显式恢复。工作区继承不等于命令批准，子命令继续经过当前用户审批和
租约检查；子修改留在独立卷，进入父工作区仍需独立的可审批合并流程。

## 子工作区审批合并

安装有效子任务目录的定义提供 `workspace_merge`，参数为 `childJobId` 和可选
`resolutions`（逻辑路径到 `parent`／`child` 的映射）。来源必须是当前 Job 下已完成、
没有更新输入的子孙任务，并在同一指定网关上保留可证明的分叉基线。Workflow 节点使用
原协调工作区的基线；无法证明旧任务／续接任务来源时拒绝合并。

网关比较共同基线、父工作区和子工作区，保留父方独立修改，合入子方独立修改，将同一
条目双方变化、文件／目录替换及链接冲突保留为待处理。比较按条目进行，不做逐行文本
合并。调用方给出一致的明确选择后再审批；改变选择会改变绑定。没有变化时不执行写入。

计划保留内容大小／摘要、权限、数字 UID／GID、二进制文件、符号链接、硬链接及根目录
元数据，不解包到网关宿主。每快照最多 512 MiB、50,000 个树条目，每次最多 1,024 个
变化条目、512 KiB 清单。路径为 UTF-8 逻辑名称，`.` 表示工作区根目录。

每次实际合并需要当前人工批准，所有权／权限及敏感仓库元数据变化由指定角色审批。
API 或 BFF 前缀下的 `GET /approvals/{approval}/merge` 返回类型化清单；
`GET /approvals/{approval}/merge/content?side=parent&path=...` 流式读取变化条目的
`base`／`parent`／`child` 内容。独立短期只读票据由认证网关兑换，并重新检查查看权限；
票据不能执行工具，不进入 Web DTO。下载为 no-store／nosniff 附件，附带固定 SHA-256，
控制面流式检查长度与摘要。

批准绑定 Job、原调用、计划、来源链及资源版本；批准检查和执行接纳同事务提交。
Worker 随后持久等待，释放执行名额。网关以有界后台并发恢复新卷，读回比较整棵树，
再原子发布卷引用、版本和回执，父工作区不会出现半写入状态。

日志保存预留、重试期限和回执确认；重启可重建执行，丢失响应返回原回执。先于提交到达
的取消形成不可启动的墓碑，不占用其他操作槽位。取消与发布原子竞争，已提交事实保持
权威。原 Worker 租约失效后，真实回执仍可投递并消费一次。

网关日志格式 4、PostgreSQL 预览格式 17 通过受保护迁移增加状态。Worker 协议 11 和
网关协议 4 需匹配部署。SDK 提供 `mergeReview` 和流式 `mergeContent`，
`UiAction::ViewWorkspaceMerge` 标识查看入口。App UI 继续等待 Penpot 设计。
跨网关传输、远程产物存储及完整保留／备份／滚动升级验收继续单独实施。

## 迁移与验证

PostgreSQL 格式 11 增加作用域化准备／回执和继承深度上限，保留格式 1–10。旧子会话
不会推断出更宽的委派授权。精确旧格式测试保留会话、Memory 和暂存子任务，在故障时
回滚到旧标记。网关格式 3 原子升级格式 1–2，保留环境、命令回执和快照。

真实 Docker 测试覆盖子任务修改后与重启后的 fork 重试、公布失败、半复制环境拒绝
获取、拒绝接管其他账本卷。已认证网关测试丢弃准备确认后取回相同回执，并验证继承文件、
子写入不修改父工作区。

独立可执行测试运行一个控制面、一个网关和两个 Worker，覆盖两个用户、真实父／子
Job、十四次模型请求、四次人工命令审批、私有 Memory 及 SIGTERM 退出。模型采用确定性
fixture；任务树取消见[控制](CONTROL.zh.md)。可审批合并、跨网关传输、
Workflow／Council 和剩余 P5–P6 验收继续推进。

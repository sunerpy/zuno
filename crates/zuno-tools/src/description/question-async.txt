Unattended ordinary questions auto-defer after 120 seconds without submitting an answer or waking the model. User interaction snoozes the deadline. The stable question and saved drafts remain available for a later answer; no highlighted or recommended choice is automatic.

Only the root agent asks ordinary user questions. A child returns any required decision and evidence to its parent instead of asking the user directly. This is not a replacement for native permission or required external-input controls.

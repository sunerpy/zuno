Discover and read reusable skill instructions through progressive disclosure.
Use action `list` to page through index and search-only skills, or action `search` with a concise task intent; optional search `limit` is 1-20. Explicit-only skills are intentionally omitted. Metadata results include `source` only when enabled same-named skills require disambiguation.
Use action `load` with the selected `name` and any advertised `source`. Follow `next_cursor` until `complete` before acting; a partial SKILL.md is not usable guidance.
Use action `read_resource` with the same `name` and `source`, a relative `path` such as `references/ci.md`, and any returned continuation cursor. Do not use shell, find, glob, or broad filesystem scans to rediscover an advertised skill or locate its referenced files.

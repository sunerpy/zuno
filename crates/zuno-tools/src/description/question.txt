Ask a structured Plan clarification that cannot be discovered from available evidence.
This Plan question waits for the first response. Choosing Defer releases the tool's
wait without supplying an answer or authorizing Work. Use question_async for optional
clarification while continuing independent planning.

Usage notes:
- Ask only when the answer materially changes the outcome and cannot be discovered from available evidence
- Defer non-blocking choices and do not ask for reassurance
- Prefer one concise question and ask no more than three at once
- When `custom` is enabled (default), a "Type your own answer" option is added automatically; don't include "Other" or catch-all options
- Provide 2-3 mutually exclusive options; set `multiple: true` only when combinations are meaningful
- If you recommend a specific option, make that the first option in the list and add "(Recommended)" at the end of the label
- The request persists independently of this tool call; the user may answer later or choose Defer
- Tool results are receipts. Actual answers arrive through the durable session inbox once
- A partial or empty answer leaves the unanswered items pending; skipping, a saved draft, or silence is never approval
- Cancellation is a refusal, not an answer; do not fabricate a selection
- To request authorization of an exact Plan for Work, use plan_exit, not a generic question

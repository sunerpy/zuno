Writes a file to the local filesystem.

Usage:
- This tool will overwrite the existing file if there is one at the provided path.
- Only `filePath` and `content` are required.
- If this is an existing file, read that exact file first. Zuno tracks its content digest for the current session and rejects stale writes after an external change.
- The stale-read guard compares the exact bytes recorded by `read`; it does not depend on a Git repository, index, or status.
- ALWAYS prefer editing existing files in the codebase. NEVER write new files unless explicitly required.
- NEVER proactively create documentation files (*.md) or README files. Only create documentation files if explicitly requested by the User.
- Only use emojis if the user explicitly requests it. Avoid writing emojis to files unless asked.
- Do not use a full-file write as a blind fallback after native patch or `git apply` failure; re-read first and replace the whole file only when that replacement is intentional. Never use `git reset --hard` or `git checkout --` to manufacture the expected pre-image.
Example: {"filePath":"/workspace/new.txt","content":"complete file contents\n"}

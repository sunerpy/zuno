Create a durable goal only when explicitly requested by the user or higher-priority instructions. Do not infer a goal from ordinary work. Preserve the requested objective without narrowing it. success_criteria is required: name at least one concrete check that decides whether the objective is met, stated as the check itself rather than as the outcome you hope for. Blank entries are not criteria, and the list is immutable to the model after creation, so a proposal with nothing to check is refused rather than accepted as a question. The result assigns each criterion a short id, such as c1, to cite later. Completing the goal closes every criterion you recorded: name each one in goal_update, either with the receipt id printed by the tool result that verified it or with the reason it will not be verified. An unfinished goal cannot be replaced. Set token_budget only when the user explicitly requested a positive budget.

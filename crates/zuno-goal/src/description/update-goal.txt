Read the current goal before changing it and pass its revision as expected_revision. If the revision is stale, read again instead of overwriting concurrent work. Mark it complete only when authoritative evidence proves every requirement and no required work remains. Close each success criterion in the same call: name it in satisfy_criteria with the receipt id printed by the tool result that verified it, or in waive_criteria with the reason it will not be verified. A goal that changed the workspace cannot complete while any criterion is still open, and editing files after a criterion was satisfied reopens it, so run the check again after the last change and cite the new receipt. Report blocked only with a concrete blocking_condition after the same true impasse persists for three consecutive goal turns and meaningful progress is impossible without user input or external change. Do not use this tool merely because a turn is ending, work is difficult, the budget is low, or more verification remains.
